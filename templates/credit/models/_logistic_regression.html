How it works

Logistic regression adds up the standardized features with one weight each and passes the sum through the logistic function, which turns it into a probability of default between 0 and 1. The weights are learned by maximizing the likelihood of the training labels (Cox, 1958; Hosmer et al., 2013), with a penalty that keeps them small.

Why it fits this problem

The data are tabular and defaults are rare. Balanced class weights make each default count more during training, which raises the recall of the default class. It is also the natural baseline to judge the other models.

Strengths and limits

It is fast, tiny (one weight per feature) and the easiest to explain, because each weight shows how a feature moves the risk. It is sensitive to scale, so the numeric features are standardized, and it only draws linear relations: it cannot capture interactions between features unless they are added by hand.
